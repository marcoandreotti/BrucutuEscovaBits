# Laboratórios

Os laboratórios são desafios práticos para transformar conceitos em evidência. Cada atividade deve ser pequena o bastante para terminar, mas rica o bastante para gerar uma decisão ou observação.

## Formato esperado

Um laboratório futuro deverá conter:

- objetivo e pergunta investigada;
- pré-requisitos e ambiente seguro;
- passos reproduzíveis;
- resultado esperado e critérios de sucesso;
- observações, trade-offs e perguntas de reflexão;
- limpeza do ambiente, quando necessário.

## Laboratórios planejados

- [Arquitetura de mensageria e observabilidade](arquitetura-mensageria-observavel/README.md): experimento guiado com RabbitMQ, telemetria, logs estruturados e Serilog.
- [Brucutu.AI: Enterprise Generative AI Playground](brucutu-ai/README.md): conceitos e experimentos propostos em nove etapas, da API com modelo de linguagem ao uso de agentes e MCP, com arquitetura, segurança e custos.
- Comparar duas decomposições para uma API de catálogo.
- Medir o efeito de um índice em uma consulta.
- Introduzir um teste em um trecho de código fossilizado.
- Simular timeout e fallback em uma integração.

Os itens sem link continuam planejados. Os laboratórios com link têm material de estudo em Markdown; cada um informa seu estágio e os recursos disponíveis. No Brucutu.AI, os capítulos conceituais e os roteiros estão disponíveis, enquanto a aplicação executável e seu ambiente ficam para uma implementação futura.
