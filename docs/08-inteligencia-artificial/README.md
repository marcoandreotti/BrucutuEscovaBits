# Inteligência artificial na engenharia de software

Esta área trata do uso responsável de IA para analisar, planejar, implementar, testar e documentar software. A proposta é construir um acervo de abordagens e ferramentas, sempre preservando revisão humana, rastreabilidade e o código como fonte da verdade operacional.

## Artigos

- [IA na engenharia de software](ia-na-engenharia-de-software.md) — possibilidades, limites, revisão humana e rastreabilidade.
- [Agentes, skills, memória e orquestração](agentes-skills-memoria-e-orquestracao.md) — como estruturar trabalho com agentes especializados.
- [Fluxo rastreável de desenvolvimento com IA](fluxo-rastreavel-com-ia.md) — da demanda ao commit, testes, documentação e Pull Request.
- [Acervo de ferramentas de IA](acervo-de-ferramentas-de-ia.md) — categorias, critérios de escolha e ferramentas conhecidas pelo projeto.

## Princípios desta área

- IA sugere; pessoas responsáveis decidem.
- O código executável, os testes e os registros do projeto são a fonte de verdade.
- Toda alteração deve ser revisável, testável e rastreável.
- Contexto, memória e instruções precisam ser versionados quando influenciarem o resultado.
- Velocidade sem compreensão apenas produz código fossilizado mais rápido.
