# Imagens globais

Esta pasta reúne imagens compartilhadas pelo portfólio Brucutu Lava Bits, como hero do README, mascote e ilustrações institucionais.

## Arquivos atuais

| Arquivo | Uso | Texto alternativo sugerido |
| --- | --- | --- |
| `brucuto-genio.png` | Imagem principal do README | Brucutu Lava Bits: personagem pré-histórico apresentando conceitos de tecnologia |
| `brucutu-ideia.png` | Apoio visual à missão educacional | Brucutu segurando uma pedra com símbolos de código e arquitetura |
| `icone.png` | Ícone e mascote em fundo transparente | Ícone ilustrado do mascote Brucutu |

Ao adicionar uma imagem:

- use um nome descritivo, em minúsculas e separado por hífens;
- registre o uso e o texto alternativo nesta tabela;
- confirme autoria, origem e licença antes de publicar;
- prefira caminhos relativos a partir do documento que fará a referência;
- evite duplicar uma imagem que já possa ser reutilizada.

Imagens específicas de diagramas ou banners podem ser organizadas em `assets/diagramas/` e `assets/banners/` quando deixarem de ser apenas material global do portfólio.
