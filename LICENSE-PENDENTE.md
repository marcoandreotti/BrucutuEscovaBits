# Licença pendente

Este projeto ainda não possui uma licença definida. Nenhuma licença ou atribuição de autoria foi inventada nesta etapa.

Antes da publicação, os responsáveis precisam decidir:

1. quais partes do projeto serão licenciadas (documentação, código de exemplo, imagens e diagramas);
2. se haverá licenças diferentes para conteúdo textual e código;
3. quem será atribuído como autor ou organização mantenedora;
4. quais avisos de terceiros e regras de contribuição serão necessários.

Até essa decisão, trate o conteúdo como não licenciado para redistribuição. Substitua este arquivo pelos avisos de licença aprovados antes de publicar o projeto.
